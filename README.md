# RashmiCreativesArtSpace 🎨✨

Official web platform for **RashmiCreativesArtSpace** — Designing, Industrial Printing, Physical Branding & Digital Marketing solutions based in Malad East, Mumbai.

🌐 **Live Website:** [https://frontend-seven-fawn-hmo08y5yt8.vercel.app](https://frontend-seven-fawn-hmo08y5yt8.vercel.app)

---

## 🌟 Key Highlights

- **Work Done Gallery:** High-resolution 34-project execution showcase with full-screen interactive preview lightbox.
- **Interactive Service Matrix:** Seamless switching across Designing, Printing, Branding, and Digital Growth divisions.
- **Smart WhatsApp Inquiry Integration:** Pre-filled inquiry message templates on all service buttons, gallery photos, and contact cards for 1-tap inquiries.
- **Visual Design:** Vibrant editorial aesthetics with dynamic color gradients, fluid animations, and responsive layouts.
- **Direct Connect:** Quick call, WhatsApp, and official Instagram integration (`@rashmi_creatives`).
